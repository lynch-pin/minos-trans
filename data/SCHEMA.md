# `entries.json` 형식

사이트의 모든 내용은 `data/entries.json` 하나에서 나옵니다. 최상위는 항목 배열입니다.

새 항목은 Claude Code 대화에서 "이거 추가해줘" 라고 하면 이 형식에 맞춰 덧붙습니다.
직접 손으로 넣어도 됩니다.

## 항목 하나

```jsonc
{
  "id": "boro-na-eho-ton-logariasmo",  // 파일 안에서 유일한 값. 로마자+하이픈.
  "added": "2026-09-24",         // 추가한 날짜 (YYYY-MM-DD)
  "kind": "phrase",              // phrase | word
  "category": "카페·식당",         // 상황 분류. 모아보기 칩과 집계가 이걸 씁니다.
  "source": "",                  // 출처. 직접 쓴 것은 "". 옮겨 온 것은 그 출처 이름.
  "ko": "계산서 주시겠어요?",       // 하고 싶은 말 (한국어)
  "romanization": "",            // 한국어가 표제어일 때의 발음. 보통 "".
  "el": "Μπορώ να έχω τον λογαριασμό, παρακαλώ;",  // 그걸 그리스어로 (자연스러운 표현)
  "literal_el": "",              // 직역이 도움이 될 때만. 없으면 "".
  "meaning": "식당에서 계산할 때 쓰는 표현.",  // 언제 어떻게 쓰는지
  "ipa": "boˈro na ˈexo ton loɣarjazˈmo paraˈkalo",   // el 전체의 IPA (표준 현대 그리스어)
  "ko_pron": "보로 나 에호 톤 로가리아즈모 파라칼로",     // 한글 근사. 장모음은 "-" 로 표시
  "words": [                     // el 에 쓰인 낱말을 나온 순서대로
    {
      "surface": "λογαριασμό",   // 문장에 나타난 그대로
      "base": "λογαριασμός",     // 사전형(주격 단수). 같으면 같은 값.
      "pos": "명사 (남성, 대격)",   // 품사. 명사는 성과 격, 동사는 시제·상을 함께.
      "ipa": "loɣarjazˈmo",      // 이 표면형의 IPA
      "meaning": "계산서",         // 이 문맥에서의 뜻
      "note": "λογαριασμός → λογαριασμό (대격)"  // 덧붙일 말. 없으면 "".
    }
  ],
  "notes": ["문법 노트 배열. 없으면 []."],
  "examples": [{ "el": "...", "ko": "..." }],  // 예문 쌍. 없으면 [].
  "equivalent": {                // 뜻이 통하는 상대 언어의 고유 표현
    "el": "", "literal": "", "note": ""   // 없으면 el 을 "" 로.
  },
  "tags": ["필수", "패턴"]        // 문법 주제나 성격. 검색에 걸립니다.
}
```

## 규칙

- `words` 는 **`el` 에 쓰인 낱말**을 담습니다. 한국어 낱말이 아닙니다.
  사이트의 단어장이 이걸 `base` 기준으로 모아 보여 주기 때문입니다.
- 관용구처럼 굳어진 덩어리는 낱말로 쪼개지 말고 한 항목으로 두고 `note` 에 밝힙니다.
- `kind`
  - `phrase` — 문장·표현. **오늘의 표현**이 여기서만 고르고, 집계의 "문장" 수도 이것만 셉니다.
  - `word` — 낱말 하나. 문장이 아니라 단어 자체를 설명할 때 씁니다.
- `source` 는 **어디서 온 내용인지**를 남깁니다. 분류를 옮겨도 이 값은 그대로라
  나중에 한 출처만 통째로 걷어낼 수 있습니다. 직접 쓴 문장은 `""` 입니다.
- `category` 는 자유롭게 정해도 되지만, 이미 있는 이름을 쓰면 칩이 늘지 않아 보기 좋습니다.
  현재 쓰는 이름: 인사, 소개, 언어·소통, 예의, 카페·식당, 쇼핑, 길·교통,
  약속·시간, 감정·반응, 건강·곤란, 스몰토크, 숙소·생활, 자연·풍경
- 빈 값은 키를 빼지 말고 `""` 또는 `[]` 로 둡니다. 화면 쪽에서 분기가 단순해집니다.
- 항목이 수천 개로 늘면 그때 파일을 쪼개면 됩니다. 그 전까지는 한 파일로 충분합니다.

## 발음

`tools/ipa.py` 에 낱말별 IPA·한글 근사 사전이 있고, 문장 발음은 거기서 조립합니다.
새 낱말이 생기면 그 사전에 먼저 넣은 뒤 다시 생성하세요. 사전에 없으면
`?` 가 남고 `tools/validate.py` 가 실패시킵니다.

- 기준은 표준 현대 그리스어(Standard Modern Greek, Δημοτική)입니다.
- 강세(τόνος)는 그리스어 정서법대로 원문에 표기하고, IPA 에는 강세 음절 앞에
  `ˈ` 로 표시합니다. 강세가 없는 그리스어 문장은 그 자체로 오류입니다.
- 한글 근사는 어디까지나 근사입니다. `θ`(무성 치간음), `δ`(유성 치간음),
  `ɣ`(유성 연구개 마찰음), `x`(무성 연구개/구개 마찰음), `ð` 는 한글에
  정확히 대응하는 글자가 없어 가장 가까운 글자를 씁니다 — 자세한 대응표는
  `tools/ipa.py` 머리말을 참고하세요.
- 모음 축약(예: 두 모음이 이어질 때의 활음화)이나 자음 앞 비음 탈락(예: την
  뒤 무성음)처럼 발음이 표기와 달라지는 경우는 `notes` 에 적어 둡니다.

## 품질에 관하여

그리스어는 원어민 검수를 거치지 않았습니다. 학습용으로 쓰시되,
중요한 자리에 쓸 문장은 따로 확인하시는 편이 좋습니다.
